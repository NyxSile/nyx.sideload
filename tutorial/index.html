Инструкция по установке с ПК

Как установить сторонние приложения без лимитов и Enterprise-сертификатов

Почему ПК-сайдлоуд надежнее?

Использование компьютера позволяет вам создать свой собственный личный сертификат разработчика (используя ваш личный Apple ID). В отличие от бесплатных общих сертификатов на сайте, этот сертификат невозможно отозвать со стороны Apple, и он работает на 100% стабильно.

LiveContainer SideStore All-in-One

Метод 1: LiveContainer

Запуск неограниченного числа IPA без реальной установки

  1. Подключите устройство

    Подсоедините ваш iPhone или iPad к компьютеру через USB-кабель. Разблокируйте экран и нажмите «Доверять этому компьютеру», если появится запрос.

  2. Запустите Nyx.Loader

    Скачайте Nyx.Loader (ссылки есть в окне «Сайдлоуд с ПК» на главной странице), запустите его и выберите LiveContainer. Apple ID вводите только внутри Nyx.Loader — этому сайту он не нужен.

  3. Доверьте сертификат

    После завершения установки откройте Настройки → Основные → VPN и управление устройством на телефоне, найдите ваш Apple ID в списке и нажмите кнопку «Доверять».

  4. Пользуйтесь приложениями

    Запустите LiveContainer на телефоне. Теперь вы можете добавлять любые скачанные IPA файлы внутрь контейнера. Они будут работать мгновенно и без ограничений на 3 установленных приложения.

Метод 2: SideStore

Полноценный магазин приложений с обновлением по Wi-Fi

  1. Установите SideStore

    Используйте Nyx.Loader так же, как в первом методе, но выберите SideStore.

  2. Установите LocalDevVpn

    Скачайте официальное приложение LocalDevVpn из App Store. Оно необходимо для фоновой подписи программ прямо на вашем устройстве.

  3. Импортируйте конфигурацию

    Скачайте файл конфигурации LocalDevVpn (доступен при установке) и импортируйте его в приложение LocalDevVpn. Включите этот VPN-туннель.

  4. Подписывайте приложения на ходу

    С включенным LocalDevVpn откройте SideStore. Теперь вы можете устанавливать сторонние IPA прямо со своего телефона без использования компьютера!

Метод 3: All-in-One (Рекомендуемый)

Комбинация лучших решений для максимального удобства

Идеальное комбо

Установка метода All-in-One загружает на ваше устройство и SideStore, и LiveContainer одновременно, автоматически привязывая наш встроенный репозиторий приложений nyx.apps.

Как это работает?

  • SideStore используется для управления фоновой подписью самого себя и критических системных утилит.
  • LiveContainer берет на себя все остальные игры и тяжелые приложения, чтобы не тратить лимиты свободных слотов Apple ID (у обычного Apple ID лимит равен 3 приложениям).
